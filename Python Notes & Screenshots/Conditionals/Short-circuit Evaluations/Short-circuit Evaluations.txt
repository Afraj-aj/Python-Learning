Short-circuit Evaluations
=========================

Concept
-------
Evaluation of an expression stops as soon as its result is determined. With
`and` and `or`, the result may be one of the operands rather than a Boolean.

and operator
------------
Stops if the first operand is falsy and returns it; otherwise evaluates and
returns the second operand. The second operand is evaluated only when the
first is truthy.

or operator
-----------
Stops if the first operand is truthy and returns it; otherwise evaluates and
returns the second operand. The second operand is evaluated only when the
first is falsy. `not` evaluates its operand and returns a Boolean, so it is not
short-circuiting.

Example:
    # AND short-circuit
    False and print("Hello")   # print() is never called
    True and print("Hello")    # print() is called

    # OR short-circuit
    True or print("Hello")     # print() is never called
    False or print("Hello")    # print() is called

    # Practical example
    username = ""
    # startswith(prefix) returns True if the string begins with that prefix.
    if username and username.startswith("admin"):
        print("Admin user")

    # If username is empty (falsy), the second part is not evaluated
    # This prevents potential errors
    greeting = username or "Guest"
    print(greeting)  # "Guest" when username is empty
