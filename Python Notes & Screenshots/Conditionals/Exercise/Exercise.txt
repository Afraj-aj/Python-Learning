Exercise
========

Practice
--------
Try each exercise before looking at the example solution. These examples use
`if`, `elif`, `else`, comparison operators, and logical operators.

Check an age
------------
Print "Adult" when the age is at least 18; otherwise, print "Minor".

Example:
    age = 16
    if age >= 18:
        print("Adult")
    else:
        print("Minor")
    # Output: Minor
    # Boundary: age = 18 prints "Adult".

Check a number
--------------
Print whether a number is positive, negative, or zero.

Example:
    number = -3
    if number > 0:
        print("Positive")
    elif number < 0:
        print("Negative")
    else:
        print("Zero")
    # Output: Negative

Check a range
-------------
Print a message when a score is from 0 through 100, inclusive.

Example:
    score = 85
    if 0 <= score <= 100:
        print("Valid score")
    else:
        print("Invalid score")
    # Output: Valid score
    # Boundaries: 0 and 100 are valid; -1 and 101 are invalid.

Combine conditions
------------------
Grant access only when a person is at least 18 and has an ID.

Example:
    age = 20
    has_id = True
    if age >= 18 and has_id:
        print("Access granted")
    else:
        print("Access denied")
    # Output: Access granted
