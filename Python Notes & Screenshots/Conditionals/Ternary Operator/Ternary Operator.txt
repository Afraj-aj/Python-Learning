Conditional Expression (Ternary Expression)
===========================================

Purpose
-------
Provides a concise, one-line syntax for choosing between two expressions.
It is often informally called Python's ternary operator.

Syntax
------
    value_if_true if condition else value_if_false
The condition uses Python truth testing. Exactly one of the two value
expressions is evaluated, and the expression returns that value (it does not
necessarily return a Boolean).

Benefit
-------
Reduces the number of lines needed for simple if/else logic when assigning
values to a variable.

Example:
    # Without ternary operator
    age = 20
    if age >= 18:
        status = "Adult"
    else:
        status = "Minor"

    # With ternary operator
    status = "Adult" if age >= 18 else "Minor"

    # More examples
    num = 7
    result = "Even" if num % 2 == 0 else "Odd"

    temperature = 30
    message = "Hot" if temperature > 25 else "Pleasant"

    # The unselected expression is not evaluated
    result = "available" if True else 1 / 0
    print(result)  # available
