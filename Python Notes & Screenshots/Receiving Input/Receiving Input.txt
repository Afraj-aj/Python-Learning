Receiving Input
===============

Purpose
-------
Used to read data from the terminal (user input) while a program is running.

Syntax
------
`input(prompt=None)` reads one line from standard input. The prompt is
optional; when provided, it is written without a trailing newline. The
returned string does not include the line-ending newline. If input reaches
end-of-file, `input()` raises `EOFError`.

Example:
    name = input("Enter your name: ")
    print(f"Hello, {name}!")

    # No prompt is required
    response = input()

Return Type
-----------
The input() function always returns a string, even if the user types a number.

Example:
    age = input("Enter your age: ")
    print(type(age))   # <class 'str'>

    # To use as a number, convert the input
    age = int(input("Enter your age: "))
    print(age + 1)     # Works after conversion

If the entered text is not a valid integer, `int()` raises a `ValueError`.
The same applies when converting invalid text with `float()`. Handle the
exception if the program should prompt again instead of stopping.

Example:
    try:
        age = int(input("Enter your age: "))
    except ValueError:
        print("Please enter a whole number.")
