Variables
=========

Purpose
-------
Used to store data in the computer's memory. A variable acts as a label
referencing a specific memory location.

Example:
    age = 25
    name = "Alice"
    height = 5.9
    is_student = True

Primitive Types
---------------
Python supports basic data types including:
    Integers:   Whole numbers (e.g., 1000).
    Floats:     Numbers with decimal points (e.g., 4.99).
    Booleans:   Logical values representing True or False. Note that Python is
                case-sensitive, so these must be capitalized.
    Strings:    Sequences of text characters.

Example:
    count = 1000          # Integer
    price = 4.99          # Float
    is_valid = True       # Boolean
    message = "Hello"     # String

Variable Names
--------------
Best Practices for Readability:
    Descriptive: Use meaningful names (e.g., student_count instead of c1) to
                make code maintainable.
    Lowercase:  Use all lowercase letters for naming variables.
    Underscores: Use underscores to separate words since spaces are not
                permitted.
    Formatting: Maintain consistent spacing around the assignment operator
                (=) for clean code compliant with PEP 8 standards.

Example:
    # Good
    student_count = 25
    total_price = 19.99
    is_enrolled = True

    # Avoid
    c1 = 25
    TP = 19.99
    IE = True
