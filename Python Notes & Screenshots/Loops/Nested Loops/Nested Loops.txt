Nested Loops
============

Definition
----------
A loop placed inside another loop (outer loop and inner loop).

Execution
---------
For every iteration of the outer loop, the inner loop starts and normally
runs to completion unless control flow exits it early. The total number of
inner-body runs is the product of the iteration counts when neither loop is
interrupted; if either loop has no iterations, the body never runs.

Applications
------------
Highly effective for working with multidimensional structures, such as
printing coordinates or processing matrix-like data.

Example:
    # Print multiplication table
    for i in range(1, 4):
        for j in range(1, 4):
            print(f"{i} x {j} = {i * j}")
        print()  # Blank line between rows

    # Print grid coordinates
    for row in range(3):
        for col in range(3):
            print(f"({row}, {col})", end=" ")
        print()  # New line after each row

`break` and `continue` affect the nearest enclosing loop only. Use separate
flags or helper functions if an inner-loop result must also stop the outer
loop.
