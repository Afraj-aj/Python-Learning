For Loops
=========

Purpose
-------
Used for repeating tasks a specific number of times or iterating over a
collection.

Range Function
--------------
Generates a sequence of numbers.
    range(x):         Generates numbers from 0 up to, but not including, x.
    range(start, end): Starts at start and ends before end.
    range(start, end, step): Increments by the step value.

Usage
-----
The loop variable (e.g., number) updates in each iteration to reflect the
current value from the range.

Example:
    # range(5) - 0 to 4
    for i in range(5):
        print(i)
    # Output: 0, 1, 2, 3, 4

    # range(2, 7) - 2 to 6
    for i in range(2, 7):
        print(i)
    # Output: 2, 3, 4, 5, 6

    # range(0, 10, 2) - step by 2
    for i in range(0, 10, 2):
        print(i)
    # Output: 0, 2, 4, 6, 8

    # Iterating over a list
    fruits = ["apple", "banana", "cherry"]
    for fruit in fruits:
        print(fruit)
    # Output: apple, banana, cherry
