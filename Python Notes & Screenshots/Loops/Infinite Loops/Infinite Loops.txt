Infinite Loops
==============

Definition
----------
A loop whose condition remains truthy, causing it to run indefinitely unless
the program exits it with control flow or an external interruption.

Exit Strategy
-------------
An intentional infinite loop can be stopped with `break` (exit the loop),
`return` (leave the current function), an exception (an error that interrupts
normal execution), or an external interruption such as Ctrl+C. A condition
that eventually becomes false is another common way to end a loop.

Risk
----
An infinite loop does not necessarily consume increasing memory, but it can
keep using CPU time and prevent later code from running. The effect depends on
what the loop body does.

Example:
    # Infinite loop with break
    count = 0
    while True:
        print(f"Count: {count}")
        count += 1
        if count >= 5:
            print("Breaking out of loop")
            break
    # Output: Count: 0, 1, 2, 3, 4, Breaking out of loop

    # User input to control exit
    while True:
        command = input("Type 'stop' to exit: ")
        if command.lower() == "stop":
            print("Exiting...")
            break
        else:
            print("Keep going!")

    # WARNING: This will run forever unless interrupted
