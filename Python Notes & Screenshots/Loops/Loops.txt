Loops
=====

Overview
--------
Loops are used to repeat code execution. This topic covers for loops,
while loops, and related concepts.
Use the individual topic notes for loop syntax, range arguments, control-flow
keywords, and loop-else behavior.

Topics in this folder:
- For Loops
- For..Else
- Nested Loops
- Iterables
- While Loops
- Infinite Loops
- The range() Function

Example:
    for i in range(5):
        print(i)
    # Output (one number per line): 0 / 1 / 2 / 3 / 4
