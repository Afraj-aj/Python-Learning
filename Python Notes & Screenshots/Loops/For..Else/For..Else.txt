For..Else
=========

Break Statement
---------------
Used to exit a loop prematurely when a specific condition is met.

Else Clause
-----------
A block of code that executes only if the loop completes fully without
encountering a `break` statement. It also runs when the iterable is empty.
Using `continue` does not skip the `else`; a `break` does. An exception that
escapes the loop prevents the `else` block from running. The same rule applies
to `while` loops.

Use Case
--------
Often used for search operations to determine if an item was found or if the
iteration finished without success.

Example:
    # Search for a number
    numbers = [1, 2, 3, 4, 5]
    target = 3

    for num in numbers:
        if num == target:
            print(f"Found {target}!")
            break
    else:
        print(f"{target} not found in the list")

    # Output: Found 3!

    # Example without break
    target = 10
    for num in numbers:
        if num == target:
            print(f"Found {target}!")
            break
    else:
        print(f"{target} not found in the list")

    # Output: 10 not found in the list

    # An empty loop completes normally, so its else block runs
    for num in []:
        print(num)
    else:
        print("No items")
    # Output: No items
