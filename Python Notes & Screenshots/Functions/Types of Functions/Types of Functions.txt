Types of Functions
==================

Task-Oriented Functions
-----------------------
Designed to perform an action, such as displaying a message. The built-in
`print(value)` function displays a value in the terminal; use it when you want
to show information to a person running the program. It returns `None`, which
means it does not give back a useful result for later calculations. A
user-defined function also returns `None` by default unless it explicitly
returns a value.

Calculation-Oriented Functions
------------------------------
Designed to calculate and return a value using the `return` statement.
`return value` ends the current function call and gives that value to the
caller (the code that called the function). Reaching the end of the function,
or using bare `return`, gives `None`. A function may also have an effect
beyond its returned value, such as displaying text; that is called a side
effect.

Benefit
-------
These are more reusable because the result can be stored in a variable,
written to a file, or processed further.

Example:
    # Task-oriented function
    def greet(name):
        print(f"Hello, {name}!")

    result = greet("Alice")  # Returns None
    print(result)  # None

    # Calculation-oriented function
    def add(a, b):
        return a + b

    total = add(5, 3)  # Returns 8
    print(total)  # 8

    # A returned value can be used directly
    print(add(2, 4))  # 6

    # Reusability
    numbers = [10, 20, 30]
    doubled = [add(x, x) for x in numbers]
    print(doubled)  # [20, 40, 60]
