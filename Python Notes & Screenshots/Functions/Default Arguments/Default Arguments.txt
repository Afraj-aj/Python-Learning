Default Arguments
=================

Purpose
-------
An optional parameter is one the caller can leave out. A default argument
sets the value that parameter uses when it is omitted, which is useful when
one value is the common choice (for example, adding 1 by default).
For example, `def increment(number, by=1)` makes `by` optional.

Behavior
--------
If no argument is provided, the function uses the default value. If provided,
the default is overridden. Default expressions are evaluated once when the
function is defined, not on every call.

Rule
----
For ordinary positional parameters, parameters with defaults must come after
parameters without defaults. A keyword-only parameter must be supplied by
name in the call; see the Keyword Arguments note for that form.

Example:
    # Default value for 'by'
    def increment(number, by=1):
        return number + by

    # Uses default value (by=1)
    result1 = increment(5)
    print(result1)  # 6

    # Overrides default value
    result2 = increment(5, 3)
    print(result2)  # 8

    # Keyword argument to override default
    result3 = increment(5, by=5)
    print(result3)  # 10

    # Rule violation - this will raise a SyntaxError
    # def bad_function(a=1, b):  # Non-default argument follows default argument
    #     pass

Mutable defaults
----------------
A mutable object is one that can be changed after it is created; lists are an
example. Avoid using one as a default value because the same object is reused
across calls. Use `None` and create a fresh object inside the function when
each call needs its own value.

Example:
    def add_item(item, items=None):
        if items is None:
            items = []
        items.append(item)
        return items

    print(add_item("pen"))   # ['pen']
    print(add_item("book"))  # ['book']
