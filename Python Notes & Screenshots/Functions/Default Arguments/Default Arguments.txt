Default Arguments
=================

Purpose
-------
Makes parameters optional by providing a default value in the definition
(e.g., `def increment(number, by=1)`).

Behavior
--------
If no argument is provided, the function uses the default value. If provided,
the default is overridden. Default expressions are evaluated once when the
function is defined, not on every call.

Rule
----
For ordinary positional parameters, parameters with defaults must come after
parameters without defaults. Keyword-only parameters follow different rules.

Example:
    # Default value for 'by'
    def increment(number, by=1):
        return number + by

    # Uses default value (by=1)
    result1 = increment(5)
    print(result1)  # 6

    # Overrides default value
    result2 = increment(5, 3)
    print(result2)  # 8

    # Keyword argument to override default
    result3 = increment(5, by=5)
    print(result3)  # 10

    # Rule violation - this will raise a SyntaxError
    # def bad_function(a=1, b):  # Non-default argument follows default argument
    #     pass

Mutable defaults
----------------
Avoid using a mutable object such as a list as a default value: the same
object is reused across calls. Use `None` and create a fresh object inside
the function when each call needs its own value.

Example:
    def add_item(item, items=None):
        if items is None:
            items = []
        items.append(item)
        return items

    print(add_item("pen"))   # ['pen']
    print(add_item("book"))  # ['book']
