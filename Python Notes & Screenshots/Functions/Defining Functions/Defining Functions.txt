Defining Functions
==================

Purpose
-------
Used to break large programs into smaller, maintainable, and reusable chunks
of code.

Syntax
------
Starts with the `def` keyword.
Followed by a descriptive name (using lowercase letters and underscores).
Ends with parentheses `()` and a colon `:`.
The code block belonging to the function must be indented.

Best Practices
--------------
PEP 8 recommends two blank lines between top-level function and class
definitions. Inside a class, use one blank line between methods.
Calling a function runs its body; defining it alone does not. A function that
reaches the end without returning a value returns `None`. A `return` statement
ends the current call immediately; a bare `return` also returns `None`.

Example:
    def greet():
        print("Hello, world!")

    def add_numbers(a, b):
        result = a + b
        print(result)

    # Call the functions
    greet()          # Hello, world!
    add_numbers(3, 5)  # 8

    def divide(a, b):
        if b == 0:
            return None
        return a / b

    print(divide(5, 2))  # 2.5
    print(divide(5, 0))  # None
