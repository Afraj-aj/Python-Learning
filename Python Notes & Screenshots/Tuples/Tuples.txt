Tuples
======

Definition
----------
Similar to lists, tuples are ordered collections. The comma creates a tuple;
parentheses are commonly used to group its items. `()` is the empty tuple;
`tuple(iterable)` makes a tuple from an iterable (an object that supplies
items one by one). A non-iterable argument raises `TypeError`.
Tuples are ordered and immutable: after creation, items cannot be replaced,
added, or removed. An object stored inside a tuple may itself be mutable and
change internally.

Use Case
--------
Use when the tuple's item references should stay fixed. Immutability does not
make mutable objects stored inside the tuple immutable.

Example:
    coordinates = (10, 20)
    colors = ("red", "green", "blue")
    single = (42,)   # Single-element tuple needs a trailing comma
    also_single = 42, # Parentheses are optional; the comma is what matters
    empty = ()
    letters = tuple("abc")  # ('a', 'b', 'c')

Accessing Elements
------------------
Access elements the same way as lists, using indexes and slicing.
An invalid integer index raises `IndexError`; slices use the same omitted
bounds, negative indexes, steps, and clipping rules as list slices.

Example:
    point = (3, 7, 9)
    point[0]     # 3
    point[-1]    # 9
    point[0:2]   # (3, 7)
    point[::-1]  # (9, 7, 3)
    # point[3]   # IndexError

Tuple unpacking
---------------
Unpacking assigns tuple items to names. The number of targets must match the
number of items unless one target uses `*` to collect the remaining items.
Otherwise Python raises `ValueError`.

Example:
    x, y = (3, 7)
    first, *middle, last = (1, 2, 3, 4)
    print(x, y)                 # 3 7
    print(first, middle, last)  # 1 [2, 3] 4
    # x, y = (1, 2, 3)          # ValueError: too many values to unpack

Immutability
------------
Attempting to modify a tuple raises a TypeError.

Example:
    point = (3, 7)
    # point[0] = 5   # TypeError: 'tuple' object does not support item assignment

    # A tuple cannot be changed, but a mutable item inside it can be changed
    values = ([1, 2],)
    values[0].append(3)
    print(values)  # ([1, 2, 3],)

    # count(value) tells how many matches exist; index(value, start, stop)
    # finds the first matching position in an optional search range.
    nums = (1, 2, 2, 3)
    nums.count(2)    # 2
    nums.index(3)    # 3
    nums.index(2, 2) # 2 (start searching at index 2)
    # nums.index(9)  # ValueError: value is not present
