Formatted Strings
=================

Usage
-----
Prefixed with an f or F, these allow you to inject variables or expressions
directly into a string.
F-strings were introduced in Python 3.6. This note uses the debug `=` form,
which requires Python 3.8 or later. Python 3.12 expanded the expressions
allowed inside replacement fields; older versions may reject some newer
syntax. The examples here use syntax supported from Python 3.8.

Syntax
------
Use curly braces {} to contain variables or valid Python expressions that are
evaluated at runtime.
Double braces `{{` and `}}` display literal braces. A replacement field can
also include a conversion (`!s`, `!r`, or `!a`) and a format specification
after `:`. The expression is evaluated when the f-string is created. The
conversion selects `str()`, `repr()`, or `ascii()` output, respectively; the
format specification is interpreted by the value's type.

Example:
    name = "Alice"
    age = 30

    # Without formatted string
    greeting = "Hello, my name is " + name + " and I am " + str(age)
    print(greeting)

    # With formatted string
    greeting = f"Hello, my name is {name} and I am {age}"
    print(greeting)   # Hello, my name is Alice and I am 30

    # Expressions inside braces
    result = f"The sum of 2 + 3 is {2 + 3}"
    print(result)   # The sum of 2 + 3 is 5

    # Using uppercase F works the same
    message = F"{name} is {age} years old."
    print(message)   # Alice is 30 years old.

    # Literal braces are doubled
    print(f"{{name}}")  # {name}

    # Conversions and format specifications
    value = 3.14159
    print(f"{value:.2f}")   # 3.14
    print(f"{value:.{2}f}")  # 3.14 (nested replacement field in format spec)
    print(f"{name!r}")      # 'Alice' (repr conversion)
    label = "café"
    print(f"{label!a}")     # 'caf\xe9' (ASCII-only repr conversion)
    print(f"{label!s}")     # café (str conversion)
    print(f"{age=}")        # age=30 (debug form)

Unescaped single braces must form a valid replacement field; unmatched braces
raise `SyntaxError`. A malformed expression or format specification also
raises `SyntaxError`; an invalid format specification for a built-in value
raises `ValueError` or `TypeError` when formatted. Format specifications can
contain nested replacement fields. This note covers ordinary f-strings; raw
f-strings have additional backslash rules, and Python does not support
bytes-formatted strings.
