String Methods
==============

Scope
-----
This note explains selected common methods for Python's `str` (string) type,
rather than every string method available in Python.
Each listed method follows Python's case-sensitive string behavior and returns
a new string when it transforms text; strings themselves are immutable.
Immutable means the original string cannot be changed in place; a method
returns a new string value instead.

Object-Oriented Basics
----------------------
In Python, a string is an object (a value in a program). A method is a
function attached to an object and called with a dot, as in `course.upper()`.

Example:
    course = "python"
    course.upper()   # 'PYTHON'

Case Manipulation Methods
-------------------------
    upper():    Returns an uppercase copy; useful for displaying or comparing
                text without lowercase letters.
    lower():    Returns a lowercase copy; useful for case-insensitive
                comparisons.
    title():    Returns a title-cased copy; useful for simple headings. Its
                treatment of apostrophes may not match human names.

Example:
    text = "hello world"
    text.upper()   # 'HELLO WORLD'
    text.lower()   # 'hello world'
    text.title()   # 'Hello World'
    "they're HERE".title()  # "They'Re Here"; punctuation affects title casing

Whitespace Management
---------------------
    strip(chars=None):  Removes leading/trailing whitespace, or any of the
                        characters in chars when supplied.
    lstrip(chars=None): Removes from the left only.
    rstrip(chars=None): Removes from the right only.

When `chars` is supplied, it is treated as a set of characters to remove from
the edges, not as one exact prefix or suffix. With no argument, whitespace is
removed. These methods return a new string; if there is nothing to remove, the
returned string has the same contents as the original. Use them to clean
spaces or selected characters from user-entered text.

Example:
    messy = "   hello   "
    messy.strip()    # 'hello'
    messy.lstrip()   # 'hello   '
    messy.rstrip()   # '   hello'

Searching and Replacing
-----------------------
    find(sub, start=0, end=len(string)): Returns the first index in the
                                         optional search range, or -1.
    replace(old, new, count=-1): Returns a copy with up to count occurrences
                                 replaced; default replaces all.

`find()` returns -1 when no match exists; its optional start and end bounds use
the same clipping rules as string slices. `replace()` with `count=0` makes no
replacements, while a negative count means replace all. Supplying the wrong
argument type raises `TypeError`. Pass arguments in order as shown; for
example, use `sentence.find("like", 3)`, not `sentence.find("like", start=3)`.
Use `find()` to locate text and `replace()` to make a changed copy.

Example:
    sentence = "I like apples"
    sentence.find("like")   # 2
    sentence.find("orange") # -1
    sentence.find("like", 3) # -1 (start searching at index 3)
    sentence.find("like", 0, 6)  # 2 (end bound is excluded)
    # sentence.find("like", start=3)  # TypeError: str.find() takes no keyword arguments
    sentence.replace("apples", "oranges")   # 'I like oranges'
    sentence.replace("l", "L", 1)  # 'I Like apples' (replace first match only)
    sentence.replace("l", "L", 0)  # unchanged; count=0 replaces none

`find("")` returns an index even when no visible characters are present; for
an empty search string it returns the start position, clipped to the string
length, or `-1` if the start is past the end.

Example:
    word = "Python"
    word.strip("Pn")  # 'ytho' (removes any of these chars from either edge)
    word.replace("", "-")  # '-P-y-t-h-o-n-'
    changed = word.upper()
    print(word, changed)  # Python PYTHON; the original was not changed

Membership Operators
--------------------
    in:         Checks for the existence of a character or sequence within a
                string, returning a Boolean (True or False).
    not in:     Checks if a character or sequence is absent from the string,
                returning a Boolean.

Example:
    word = "python"
    "py" in word     # True
    "xyz" in word    # False
    "abc" not in word  # True
    "" in word         # True (empty substring)
    # "py" in 12       # TypeError: the left operand must be a string
