Lists
=====

Definition
----------
Lists store collections of items using square brackets [].
They are ordered and mutable (items can be changed after creation).

Example:
    numbers = [1, 2, 3, 4, 5]
    names = ["Alice", "Bob", "Charlie"]
    mixed = [1, "hello", 3.14, True]

Accessing Elements
------------------
Access elements via index (starts at 0; negative index accesses from the end).

Example:
    fruits = ["apple", "banana", "cherry"]
    fruits[0]    # 'apple'
    fruits[1]    # 'banana'
    fruits[-1]   # 'cherry' (last element)
    fruits[-2]   # 'banana' (second from end)

Slicing
-------
Slicing [start:end] returns a new list excluding the end index.

Example:
    numbers = [10, 20, 30, 40, 50]
    numbers[1:4]    # [20, 30, 40]
    numbers[:3]     # [10, 20, 30]
    numbers[2:]     # [30, 40, 50]
    numbers[:]      # [10, 20, 30, 40, 50] (copy of list)
