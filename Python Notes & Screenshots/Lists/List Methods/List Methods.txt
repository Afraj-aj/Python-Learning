List Methods
============

Overview
--------
Useful methods for modifying and working with lists.

Common Methods
--------------
    append(item):   Adds an item to the end of the list.
    insert(i, x):   Adds an item at a specific index.
    remove(item):   Deletes the first occurrence of the specified item.
    clear():        Removes all items from the list.
    len(list):      Returns the number of items in the list.

Example:
    numbers = [1, 2, 3]

    # append - add to end
    numbers.append(4)
    print(numbers)   # [1, 2, 3, 4]

    # insert - add at index
    numbers.insert(1, 10)
    print(numbers)   # [1, 10, 2, 3, 4]

    # remove - delete an item
    numbers.remove(10)
    print(numbers)   # [1, 2, 3, 4]

    # clear - empty the list
    numbers.clear()
    print(numbers)   # []

    # len - list size
    fruits = ["apple", "banana", "cherry"]
    print(len(fruits))   # 3
