List Methods
============

Overview
--------
This note covers the standard list methods and the `len()` built-in. Methods
that change a list modify it in place; unless noted otherwise, they return
`None`. List indexes and slice bounds follow the rules in `Lists.txt`.
Use list methods when you want to add, remove, find, count, sort, or copy list
items without writing that operation from scratch. "In place" means the
existing list itself changes. The examples below show how to use each method.

Common Methods
--------------
    append(item): Adds one item to the end; it does not unpack iterables.
    extend(iterable): Adds each item from an iterable.
    insert(index, item): Inserts before the given position. Negative indexes
                         count from the end; out-of-range indexes are clamped.
    remove(value): Removes the first equal item; raises ValueError if absent.
    pop(index=-1): Removes and returns an item; defaults to the last item.
    clear(): Removes all items.
    index(value, optional_start, optional_stop): Finds the first matching
                                                 position in optional bounds.
    count(value): Returns the number of equal items.
    sort(key=None, reverse=False): Sorts in place; returns None.
    reverse(): Reverses the list in place; returns None.
    copy(): Returns a shallow copy.
    len(items): Built-in function that returns the number of items.

`pop()` on an empty list, or with an invalid index, raises `IndexError`.
`index()` raises `ValueError` if the item is absent; `remove()` does the same.
Indexes and optional search bounds must be integers (or values Python can use
as integer indexes).
Pass method arguments in the listed order, as in `numbers.pop(0)`.
`sort()` accepts optional named settings `key` and `reverse`; `key` tells it
what value to sort by, and `reverse=True` sorts descending. `index()`'s
optional start and stop bounds follow slice rules, including negative
indexes and an excluded stop. If omitted, the search starts at the beginning
and continues to the end of the list.
`sort()` keeps equal-key items in their original order. Its optional `key`
setting is a function that returns what to compare for each item; `reverse`
chooses descending order. Values that cannot be compared raise `TypeError`
unless a suitable `key` function is supplied.
`copy()` and slicing make shallow copies: nested objects remain shared.
`len(items)` counts the items and is useful when you need the list's size.

Example:
    numbers = [1, 2, 3]

    # append - add to end
    numbers.append(4)
    print(numbers)   # [1, 2, 3, 4]

    # extend adds each element; append would add the whole list as one item
    numbers.extend([5, 6])
    print(numbers)   # [1, 2, 3, 4, 5, 6]
    letters = []
    letters.extend("ab")
    print(letters)   # ['a', 'b'] (strings are iterable)

    # insert - add before index 1
    numbers.insert(1, 10)
    print(numbers)   # [1, 10, 2, 3, 4, 5, 6]
    numbers.insert(-1, 99)  # Inserts before the current last item
    numbers.remove(99)
    numbers.insert(100, 7)  # An index beyond the end appends
    numbers.pop()            # Remove 7 before continuing

    # remove - delete an item
    numbers.remove(10)
    print(numbers)   # [1, 2, 3, 4, 5, 6]
    # numbers.remove(99)  # ValueError: value is not present

    # pop returns the removed item; the index is optional and defaults to -1
    last = numbers.pop()
    first = numbers.pop(0)
    print(last, first)  # 6 1

    # clear - empty the list
    numbers.clear()
    print(numbers)   # []

    # count and index accept a value; index also accepts optional bounds
    values = [2, 1, 2, 3]
    print(values.count(2))       # 2
    print(values.index(2, 1))    # 2
    print(values.index(2, -3, -1))  # 2 (negative start; stop is excluded)
    # values.index(2, start=1)   # TypeError: pass index arguments in order
    # values.index(9)            # ValueError: value is not present

    # sort can accept key and reverse keyword arguments
    words = ["pear", "fig", "apple"]
    words.sort(key=len, reverse=True)
    print(words)  # ['apple', 'pear', 'fig']

    # reverse mutates the list; copy makes a shallow copy
    original = [1, 2, 3]
    copied = original.copy()
    original.reverse()
    print(original, copied)  # [3, 2, 1] [1, 2, 3]

    # len - list size
    fruits = ["apple", "banana", "cherry"]
    print(len(fruits))   # 3
