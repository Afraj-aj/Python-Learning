Type Conversion
===============

Necessity
---------
Conversion is required when data types mismatch, such as attempting to
concatenate a string with a number.

Built-in Conversion Functions
-----------------------------
    int():  Converts to an integer.
    float(): Converts to a floating-point number.
    bool(): Converts to a boolean.
    str():  Converts to a string.

Truthiness and Falsiness
------------------------
Certain values are evaluated as False in a boolean context (falsy values),
including:
    Empty strings ("")
    The number zero (0)
    The None object (representing the absence of a value)

All other values are considered truthy.
