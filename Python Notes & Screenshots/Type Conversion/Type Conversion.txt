Type Conversion
===============

Scope
-----
This note covers common conversions with built-in types. It also shows the
bytes-decoding form of `str()`; custom conversion methods are outside scope.

Necessity
---------
Conversion is required when data types mismatch, such as attempting to
concatenate a string with a number. It is also necessary when performing
math on input strings (since input() always returns a string).

Example (will cause error):
    age = 25
    print("I am " + age)   # TypeError: can only concatenate str to str

Example with input:
    age = input("Enter your age: ")   # "25" (string)
    # age + 5  # TypeError
    age = int(age)                    # Convert to integer first
    print(age + 5)                    # 30

The built-in `type(value)` function tells you the value's type (what kind of
value it is). Use it when you are unsure what a value returned by a function
or conversion represents.

Example:
    type(25)       # <class 'int'>
    type("25")     # <class 'str'>

Built-in Conversion Functions
-----------------------------
`int(value)` converts a whole-number value or numeric text into an integer;
use it to do integer arithmetic with text received from `input()`.
`float(value)` converts a number or valid decimal text into a floating-point
number, useful when calculations need fractional values.
`bool(value)` gives the truth value Python assigns to a value, useful in an
`if` condition. `str(value)` makes a text representation for display or
joining a value with other text.

Example:
    int("25")       # 25
    float("2.5")    # 2.5
    bool("")        # False
    str(25)         # "25"

`int(text, base=10)` can parse text written in a number base from 2 through
36; base 0 recognizes prefixes such as `0b`. A float converted to int is
truncated toward zero, not rounded. `float()` accepts decimal text and valid
exponent notation.
Invalid numeric text raises `ValueError`; unsupported types raise `TypeError`.
An invalid base raises `ValueError`. Converting infinity to `int()` raises
`OverflowError`; converting NaN to `int()` raises `ValueError`.
Text forms such as `"inf"` and `"nan"` are valid for `float()`. A bytes-like
value can also be decoded with `str(bytes_value, encoding, errors="strict")`;
an encoding is required because bytes do not specify which text encoding to
use. The optional `errors` setting controls how invalid bytes are handled.
The default `"strict"` raises
`UnicodeDecodeError` for invalid bytes; `"replace"` substitutes U+FFFD.

Example:
    num_str = "25"
    age = int(num_str)        # 25 (integer)
    int(-3.9)                 # -3 (truncates toward zero)
    int("101", 2)             # 5 (base 2)
    int("101", base=2)        # 5 (base may be a keyword)
    int("0b101", 0)           # 5 (base inferred from prefix)
    pi = float("3.14")        # 3.14 (float)
    float("1.2e2")            # 120.0 (exponent notation)
    float("inf")              # infinity
    float("nan")              # not-a-number; comparisons have special behavior
    flag = bool(1)            # True
    bool("False")             # True (non-empty strings are truthy)
    text = str(100)           # "100" (string)
    str(b"hello", "utf-8")    # "hello" (decode bytes using UTF-8)
    str(b"caf\xc3\xa9", encoding="utf-8")  # Decodes bytes to "café"
    str(b"\xff", "utf-8", "replace")  # Replaces invalid byte with U+FFFD
    int()                     # 0; float() is 0.0; bool() is False; str() is ''
    # int(5, base=2)          # TypeError: base is only allowed with text
    # str(b"\xff", "utf-8")   # UnicodeDecodeError with the default strict mode

`bool(x)` uses truthiness rather than parsing the text as a Boolean: even
`bool("False")` is `True`. Truthiness means how Python treats a value in a
condition: as true or false. `str(object)` can call an object's `__str__()`
method (an advanced Python hook for producing display text); its exact output
depends on the object's type.

Truthiness and Falsiness
------------------------
In a Boolean context, values are treated as truthy or falsy. Falsy built-in
values include:
    False
    Numeric zero: 0, 0.0, and 0j
    None (representing the absence of a value)
    Empty strings and collections, such as "", [], (), and {}

Other built-in values are truthy. Advanced custom objects can also define how
Python tests their truth value; those special methods are outside this
beginner-level note.

Example:
    falsy_values = ["", 0, None, [], {}]
    truthy_values = ["hello", 42, 3.14, [1, 2], {"a": 1}]

    if falsy_values[0]:    # Empty string is falsy
        print("won't print")
    else:
        print("falsy!")   # This will print

    if truthy_values[0]:   # Non-empty string is truthy
        print("truthy!")  # This will print
